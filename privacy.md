# LUMEA Secondman – Privacy policy

LUMEA Secondman is a personal tool used only by its owner, Patrick Phillips.

- **What it accesses:** events in the owner's own Google Calendar (to add a shift log) and only the Google Drive files it creates itself (pictures attached to those events).
- **Where data goes:** nowhere else. Data stays in the owner's Google account and on the owner's home server. Nothing is sold, shared with third parties or used for advertising.
- **Who uses it:** only the owner.
- **Removing access:** at any time via myaccount.google.com → Security → Third-party access.
